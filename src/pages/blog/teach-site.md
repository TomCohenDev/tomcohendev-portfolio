אני מלמד הידראוליקה ותרמודינמיקה בהנדסאים. עד השבוע, כל שיעור שלימדתי היה מצגת.

עכשיו ההוראה שלי נמצאת ב־[teach.tom-cohen.com](https://teach.tom-cohen.com), ואין שם מצגות. כל שיעור הוא דף אינטרנט שבנוי מ־HTML, ‏CSS ו־three.js. התלמידים יכולים לדחוף בוכנה, לסובב מנוע ולגרור מחוון ולראות איך המספרים משתנים. וכל שיעור גם יוצא ל־PDF נקי, למי שרוצה אותו על נייר.

בניתי את האתר והעברתי אליו שני קורסים ביומיים, ב־16 וב־17 בנובמבר, בעבודה עם Claude. זה כבר שינה את הדרך שבה אני מלמד ואת הדרך שבה התלמידים שלי לומדים.

הקטעים הקצרים בפוסט נבנו באותה דרך שבה נבנו השיעורים: HTML, ‏CSS ו־three.js, שמרונדרים פריים אחרי פריים כך שייראו כמו הקלטת מסך.

## מה מצגת לא יכלה לעשות

רוב מה שאני מלמד הוא קשר בין גדלים. חוק פסקל הוא לא "הלחץ הוא 6.37 בר". הוא זה שהלחץ מתחת לשתי הבוכנות שווה. לכן כשמקטינים את הבוכנה הקטנה, הכוח ביציאה גדל, ומשלמים על זה במהלך.

שקופית מראה מקרה אחד של הקשר הזה. כדי להראות את הקשר עצמו הייתי מדבר מעל השקופית, מצייר על הלוח, או משכפל את השקופית עם מספרים אחרים ומקווה שעדכנתי כל עותק.

עותקים גם מסתירים טעויות. כשהעברתי את שיעור פסקל, Claude שם לב שבאחת השקופיות הישנות שלי שטח הבוכנה מופיע כ־A = πd². השטח הוא πd²/4. השקופית הזאת הייתה במצגת שלי הרבה זמן.

## איך נראה שיעור עכשיו

כל שיעור הוא מצגת שבנויה מסצנות. לסצנה יש שלבים, כמו שקופית עם קליקים. אבל היא קוד, אז היא יכולה לעשות כל מה שדף אינטרנט יכול:

- **שרטוטים שמציירים את עצמם**, שלב אחרי שלב, בסדר שבו הייתי מסביר אותם.
- **סימולציות עם מחוונים.** משנים קוטר ורואים את הכוח, מד הלחץ והמהלך מתעדכנים יחד.
- **תלת־ממד ב־three.js.** מנוע ארבע פעימות שאפשר לסובב, ומצוף וקורה שצפים במים.
- **הערות שנכתבו בשביל התלמידים.** בטלפון השיעור נפתח במצב קריאה: כל סצנה, וההסבר שלה מתחתיה.
- **מקור אחד לפיזיקה.** כל מספר שמופיע על המסך מגיע מקובץ פיזיקה אחד לכל שיעור, ולקובץ הזה יש בדיקות. מחוון לא יכול להראות מספר שהנוסחאות לא מסכימות איתו.

## קורס ההידראוליקה

הידראוליקה עברה ראשונה, והיא הקורס הגדול באתר. הוא מיועד להנדסאים אחרי פיזיקה ומתמטיקה בסיסיות:

- **שש יחידות:** מבוא, הידרוסטטיקה, הידרודינמיקה, מערכות הידראוליות, ניסויים בבית ונספחים.
- **26 מצגות עם 335 סצנות.** מתכונות של נוזלים ולחץ, דרך ברנולי, ונטורי ופיטו, ריינולדס, הפסדי עומד ומשאבות, ועד שסתומים, בוכנות ומעגלים בתעשייה.
- **סימולטור מעגלים** לשסתומי כיוון 4/2 ו־4/3, שסתום פריקה ושסתום חד־כיווני. התלמידים קוראים שרטוט הידראולי, ואז רואים אותו עובד.
- **ציפה בתלת־ממד.** שאלה אחת בסגנון מבחן על מצוף, קורה ומשקולת, פתורה סעיף אחר סעיף עם דג״ח. התלמידים משנים צפיפויות ומידות ורואים מה צף.
- **ניסויים עם דברים מהבית:** משקל מטבח לארכימדס, שני מזרקים כמכבש הידראולי, בקבוק עם חורים לטוריצ׳לי, צינור גינה לרציפות ולריינולדס, מייבש שיער וכדור פינג־פונג לברנולי, וחיישן הלחץ שבטלפון כדי למדוד את הגובה של בניין.
- **דף נוסחאות ומפת שאלות.** המפה מקשרת כל שאלת תרגול מתיקיית ה־Drive המשותפת שלנו לשיעור שהיא שייכת אליו.

## קורס התרמודינמיקה

בתרמודינמיקה התחלתי מהיחידה שהכי קשה לתלמידים: מחזורי מנועי בוכנה.

- **ארבע מצגות:** מנועי חום ומנוע ארבע פעימות, מחזור קרנו, מחזור אוטו ומחזור דיזל.
- **מנוע תלת־ממדי ב־three.js.** הבוכנה, הטלטל וגל הארכובה זזים, השסתומים נפתחים בפעימות הנכונות, והגז משנה צבע לפי הטמפרטורה שלו. לידו, דיאגרמת p-V מציירת את עצמה תוך כדי המחזור.
- **שאלות ממבחני הגמר** על מחזורי מנועים, מ־1996 עד 2021, כפי שהופיעו.
- **שלושה מבחנים שבנויים סביב סיפור:** חממה בערבה שפותחת לבד את חלון האוורור, משאית קירור שמובילה גלידה לאילת, ופעמון צלילה בים האדום. לכל אחד יש פתרון מלא עם הסברים, כדף אינטרנט וכ־PDF.

אין מאחורי זה שרת PDF. לכל דף יש גיליון סגנונות להדפסה: הכותרת והכפתורים של האתר נעלמים, הפתרונות המלאים נפתחים, מצגות מודפסות סצנה לעמוד ביחס 16:9, ומבחנים מודפסים על A4. כפתור ה־PDF פותח את חלון ההדפסה של הדפדפן, והקורא בוחר "שמירה כ־PDF".

## מה זה שינה

**ההסברים השתפרו.** סצנה בונה רעיון בסדר שבו הייתי מסביר אותו בכיתה, וההערות מתחתיה נכתבו בשביל התלמיד ולא בשבילי. תלמיד שפספס שיעור קורא את אותו ההסבר שהכיתה שמעה.

**המצגות ברורות יותר.** בכל סצנה רעיון אחד, עם שרטוט שמצייר את עצמו ומספרים אמיתיים. קירות הטקסט שמילאו את השקופיות שלי נעלמו.

**התלת־ממד והסימולציות עובדים.** פסקל, ברנולי ומחזור אוטו נקלטים מהר יותר כשהתלמידים יכולים לדחוף בוכנה או לסובב מנוע ולראות מה קורה.

**התלמידים לומדים בטלפון.** מצב קריאה הופך כל שיעור לדף שגוללים בו, עם ההסבר מתחת לכל סצנה.

**הם מדפיסים את מה שהם צריכים.** מבחנים, פתרונות ודף הנוסחאות יוצאים לנייר, כשזו הדרך שבה תלמיד עובד.

**זה מהיר להכין.** שיעור חדש הוא שיחה עם Claude ובדיקה מדוקדקת, הרבה יותר מהר מלבנות אותו ב־Google Slides. להחליף דוגמה לפני שיעור לוקח דקות.

## איך מקימים את זה לבד

לא צריך את הסטאק שלי. האתר שלי הוא אפליקציית Next.js עם מנוע מצגות משלה, אבל תיקייה של קובצי HTML מביאה אתכם רוב הדרך. זו הדרך הקצרה.

### 1. מתקינים את Claude Code ופותחים תיקייה

מתקינים את [Claude Code](https://claude.com/claude-code), פותחים תיקייה לקורס, ומפעילים בה את Claude:

```bash
mkdir my-lessons && cd my-lessons
git init
claude
```

Git לא חובה, אבל הוא שומר היסטוריה של כל שינוי, ואחסון חינמי בדרך כלל מפרסם ממנו.

### 2. מסבירים ל־Claude איך אתם מלמדים, ב־CLAUDE.md

Claude קורא את `CLAUDE.md` בתחילת כל שיחה. כותבים שם את הכללים פעם אחת, במקום לחזור עליהם בכל פרומפט. אפשר לכתוב אותו בעברית; הדוגמה כאן באנגלית:

```markdown
# My lessons

Lessons for <course> students. Each lesson is one HTML file: site/<course>/<lesson>.html

- Plain HTML, CSS and JavaScript. three.js from a CDN when a lesson needs 3D.
- A lesson is a list of 16:9 scenes. One idea per scene. Arrow keys reveal the steps.
- Under every scene, a note written for the student, not for me.
- Every number on screen comes from the lesson's physics.js. Write it first, with checks.
- SI units. g = 10 m/s² unless a question says otherwise.
- Printing: site/print.css. One scene per page at 16:9; tests on A4. No buttons on paper.
- Language: Hebrew, right to left. Calm, plain wording. No emoji.
```

### 3. הופכים את הצעדים שחוזרים על עצמם ל־skill

‏skill הוא מדריך עבודה ש־Claude טוען כשמשימה מתאימה לו. יוצרים את `.claude/skills/new-lesson/SKILL.md`:

```markdown
---
name: new-lesson
description: Create or change a lesson in site/. Use when I ask for a lesson, slides, a simulation or a test.
---

1. Read the source I give you (a PDF of old slides, exam questions, notes).
   List what the lesson must cover, and ask me if anything is unclear.
2. Write physics.js and run its checks with node.
3. Write the scenes, starting from site/_template.html.
4. Open the lesson and its print preview. Fix overflow and text that is too small.
5. Tell me what you changed from the source, and why.
```

### 4. נותנים לו חומר ישן ומבקשים שיעור אחד

מייצאים מצגת מ־Google Slides או מ־PowerPoint ל־PDF, שמים אותה בתיקייה, ומבקשים:

> תהפוך את slides/pascal.pdf לשיעור. תשמור על הסדר ועל הדוגמאות שלי. תוסיף סימולציה שבה התלמיד משנה את הקוטר של הבוכנה הקטנה ורואה את הכוח.

פותחים את הקובץ בדפדפן, מלמדים ממנו פעם אחת, ואומרים ל־Claude מה לשנות. השיעור השני הולך מהר יותר, כי התבנית, גיליון הסגנונות והכללים כבר קיימים.

### 5. דואגים שזה יודפס

כפתור ה־PDF יכול להיות `<button onclick="window.print()">PDF</button>`, ועוד גיליון סגנונות להדפסה:

```css
@media print {
  @page { size: 1280px 720px; margin: 0; } /* slides; use A4 for tests */
  .scene { break-after: page; }
  nav, button, .no-print { display: none; }
  * { print-color-adjust: exact; }
}
```

הקורא בוחר "שמירה כ־PDF" בחלון ההדפסה. בלי שרת ובלי ספריית PDF.

### 6. מפרסמים, גם בלי דומיין

אפשר לארח קבצים סטטיים בחינם, בכתובת שלא צריך לקנות:

- **Cloudflare Workers.** מוסיפים `wrangler.jsonc` ומריצים `npx wrangler deploy`. מקבלים `https://<name>.<your-subdomain>.workers.dev`. בזה אני משתמש, עם הדומיין שלי מעל.
- **GitHub Pages.** דוחפים את התיקייה ל־GitHub ומפעילים את Pages בהגדרות המאגר. מקבלים `https://<user>.github.io/<repo>`.

```jsonc
{
  "name": "my-lessons",
  "compatibility_date": "2026-11-01",
  "assets": { "directory": "./site" }
}
```

בפעם הראשונה, `npx wrangler login` מחבר את חשבון ה־Cloudflare שלכם. אחרי זה מבקשים מ־Claude לפרסם כשאתם מוכנים, או מחברים את המאגר בלוח הבקרה של Cloudflare כדי שכל push יפורסם.

## מה עדיין דורש עבודה

- **בדיקה.** Claude מצא טעות במצגות שלי, והוא יכול גם לטעות בעצמו. אני בודק כל מספר וכל הערה לפני שאני מלמד מהם. קובץ הפיזיקה והבדיקות שלו מקלים על זה מאוד.
